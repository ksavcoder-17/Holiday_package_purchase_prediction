# Holiday Package Purchase Prediction

## Project Overview
This project uses machine learning to predict whether a customer is likely to purchase a holiday package based on customer demographic and behavioral data.

## Dataset
The project uses `Travel.csv`, which contains customer information and purchase-related features.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook / Google Colab

## Machine Learning Workflow
1. Load and explore the dataset.
2. Perform data cleaning and preprocessing.
3. Handle missing values and categorical features.
4. Perform exploratory data analysis (EDA).
5. Train classification models.
6. Tune model hyperparameters.
7. Evaluate model performance using classification metrics and ROC-AUC.

## Model Evaluation
The model is evaluated using suitable classification metrics. The ROC-AUC curve can be used to assess its ability to distinguish between customers who purchase a holiday package and those who do not.

## Project Files
- `Travel.csv` — Dataset.
- `auc.png` — ROC-AUC visualization.
- `Holiday_package_purchase_prediction.ipynb` — Notebook containing the analysis and model development.
- `README.md` — Project documentation.

## Objective
To use customer data and machine learning techniques to support the prediction of holiday package purchases.
